EXCELFUN — PROTOTIPE MEDIA PEMBELAJARAN RUMUS DASAR MICROSOFT EXCEL

Isi paket:
- index.html: prototipe web interaktif yang dapat dijalankan secara lokal.

Cara membuka:
1. Ekstrak ZIP ke folder.
2. Buka index.html menggunakan browser modern (Chrome, Edge, Firefox, dan sejenisnya).
3. Tidak perlu instalasi atau koneksi internet untuk fitur inti.

Struktur halaman diselaraskan dengan Lampiran proposal:
1. Beranda
2. Petunjuk penggunaan
3. Daftar materi (Range, SUM, AVERAGE, MAX, MIN)
4. Halaman materi dengan contoh data B2:B5
5. Latihan interaktif enam soal
6. Umpan balik dan hasil, termasuk skor serta opsi coba lagi/kembali ke materi/beranda

Catatan:
- Ini prototipe lokal, belum dihosting sebagai situs publik.
- Instrumen validasi dan uji coba dalam proposal masih perlu digunakan setelah mendapat izin; paket ini tidak menyatakan bahwa validasi atau uji coba siswa telah dilakukan.
- Skor latihan hanya berjalan selama sesi di browser dan tidak disimpan ke server.
